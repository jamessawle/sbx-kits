# mise-network-hugo

Permits Hugo Extended version resolution through Mise.

## Capabilities

- Allows version resolution through `mise-versions.jdx.dev`.

## Composition

Compose with the community
[Mise kit](https://github.com/docker/sbx-kits-contrib/tree/main/mise).

## Operational notes

GitHub release hosts used for Hugo downloads are supplied by the community Mise
kit. This kit does not install Hugo or configure a project toolchain version.
